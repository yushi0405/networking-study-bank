# Contributing

Keep each question small, factual, and sourceable.

## Before opening a PR

Run:

```bash
npx --yes studyci@0.2.0 check questions
```

A contribution should:

- use a new, unique question ID
- avoid copying certification exams or commercial study materials
- cite a public primary source where possible
- avoid questions whose answer depends on vendor-specific behavior unless the source is explicit
- keep the answer short enough to review in a diff

For corrections, include the RFC or other primary source that supports the change.
